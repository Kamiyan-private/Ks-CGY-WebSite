⚔️ 聖剣争奪

同盟同士で拠点（聖剣）を奪い合う、大規模PvPイベント！

🔰 かんたんガイド

聖剣争奪のススメ

まず押さえたい要点だけ！（くわしくは下の各項目を見てね）

① 戦闘のキホン

  • 攻撃をする時は 必ず偵察 を行う！
  • 防衛をする時は 人数差 を付ける！

偵察を上手く使って、相手の戦力がどこに固まっているか確認しよう！

例）敵：Lv30・Lv28・拠点の3つが攻撃対象。偵察の結果、兵士数が 0 / 20K / 20K と判明 → Lv30の城を優先して燃やす。

拠点・自分や仲間の城を守るときは、必ず人数差をつけよう！

例）敵TG2が自分に単騎で凸 → 仲間Lv29に自分の城へ防衛を入れてもらう。
例）敵Lv30が味方に単騎凸 → 仲間へ防衛を入れる。

② 転移の仕方

  • 拠点とは 少し遠く（3城分）
  • 敵からは 遠く（5城分）
  • 味方とは 近く（ビタ付け）

①の通り、防衛を入れたりできるように敵城からは離れて転移しましょう。 また敵が拠点近くにいなくても基本飛んでくるので、拠点からもあらかじめ距離を開けましょう。

⚡ ただし！ 一刻も早く拠点に駐屯したい場合（開幕の拠点の取り合いなど）は、 拠点に ビタ付け しましょう！

❓ 「聖剣争奪」って何？

同盟イベントの一つで、簡単に言うと 同盟同士で拠点（聖剣）を奪い合う大規模PvP戦 です。

勝敗の決まり方： 「聖契ポイント」を多く稼いだ同盟の勝ち！ ポイントは拠点を占拠し、占領状態を維持することで得られます。 拠点の種類によってポイント量は異なります。

🚩 おおまかな流れ

  1. イベント開始
  2. 部隊を出して拠点へ行軍
  3. 敵と戦闘して占領
  4. 占領状態を維持（防衛）

🎁 おトクなイベント仕様

  • 兵士は死亡しません（イベント終了後に自動で全回復）。
  • イベント中は専用の 無料加速（移転・治療・行軍） が、一定時間ごとに使えます。
⚠️ 注意：イベント中に攻撃されると兵士は病院送りになります。 治療しないとイベント中の戦力が落ちるので、無料治療加速でこまめに回復を！

🏰 拠点の解放（3ステージ）

はじめから全拠点が解放されているわけではなく、3つのステージに分かれて順番に解放されます。

🥇 ステージ1

  • 最優先 厩舎：無料上級転移装置の付与時間（クールタイム）短縮 ← これが1番大事！
  • 高め 聖域（2箇所）：ポイントまあまあ大きい
  • 修道院（4箇所）：地図の4角にある
  • 鐘楼：施設占拠時間短縮 ← 欲しいけど最悪取らなくてもOK

🥈 ステージ2

  • 最重要 聖剣祭壇：マップど真ん中。ポイント最大！
  • 教化の間：自軍能力UP（バフ）
  • 傭兵駐屯地：敵能力ダウン（デバフ）

🥉 ステージ3

  • 地下室：ランダムに出現。ポイント美味しい🍯
